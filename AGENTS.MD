# Sitio web de un centro de FP
---
Este sitio web de prueba y se usará en clase de Desarrollo d eInterfaces Web.
Consiste en un sitio web para un centro formativo de FP.

## Tecnologias
- Frontend
    - HTML5 (moderno)
    - CSS3
    - Vanilla JavaScript
- Backend
    - Node.js
    - Express 4.22.3
    - Plantillas EJS

## Arquitectura
- Todo en una unica pgina index, dividido por secciones.

## Contenido de la web
- El contenido debe ser realista
- El contenido debe estar en inglés
- Las imagenes por defecto son de picsum.photos

## Convenciones del lenguaje
- Usa ingles para las variables y funciones

## Limitaciones
- No usar grid
